# Atalhos

| Atalho                 | Ação                                 |
| ---------------------- | ------------------------------------ |
| `Cmd/Ctrl + N`         | Nova nota com o modelo da disciplina |
| `Cmd/Ctrl + O`         | Abrir nota pelo nome                 |
| `Cmd/Ctrl + P`         | Procurar comandos                    |
| `Cmd/Ctrl + Shift + F` | Buscar em todas as notas             |
| `Cmd/Ctrl + E`         | Alternar edição/leitura              |

## Plugins

- **Templater:** escolhe um modelo pela pasta da disciplina.
- **Dataview:** painéis dentro do Obsidian; não são exibidos pelo Quartz.
- **Excalidraw:** esquemas desenhados.
- **Obsidian Git:** sincronização pelo painel de controle de versão.
